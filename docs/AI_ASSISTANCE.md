# AI assistance and provenance

This prototype was developed with OpenAI Codex at the participant's request. Codex inspected the organizer's ten problem statements, selected PS08 after the participant delegated the choice, and assisted with implementation, tests and documentation.

The application does not call an LLM at runtime. Scenario proposals are deterministic and clearly labeled. No API usage cost, token count or model-specific development statistics are claimed because those measurements are not available in this project.

`log.txt` is a development activity summary, not a native transcript. No complete native agent trace archive is claimed or included. The supplied PS08 statement does not explicitly require one; if organizers separately request it, export the relevant session through the supported agent interface, review it for secrets and unrelated personal information, and submit it through their official route. Do not publish authentication files or the complete local agent data directory.

All test cases and demo records are synthetic. No hidden evaluation material was accessed. Evaluation reports describe only measured local cases and do not claim real-world attack coverage or a guaranteed competition result.
